## Набор инструментов для работы с К1921ВГ015 под Windows

Здесь минимальный набор инструментов для разработки под Ирис UNO К1921ВГ015, а именно:
* Компилятор для RISC-V, который я взял из [Syntacore IDE](https://syntacore.com/tools/development-tools)
* OpenOCD с поддержкой МК и отечетсвенных программаторов, который я взял [отсюда](https://gitflic.ru/project/rus_mcu/openocd/release/8e432334-83fe-4af2-a8b4-69c3a8d6f5f6)
* Минимальный набор утилит для Windows [отсюда](https://xpack-dev-tools.github.io/windows-build-tools-xpack/docs/releases/)
