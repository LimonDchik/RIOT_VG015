/**
@defgroup    boards_bluebirdVG015 BlueBird-VG015
@ingroup     boards
@brief       Support for the BlueBird-VG015 evaluation board

## Overview

This board is based on the `k1921vg015` MCU.

The current RIOT port provides:
- one stdio UART on `UART3`
- one general-purpose timer based on `TMR32`
- one user LED on `PC0`

## Flashing the device

The board is typically flashed via BlueProg and OpenOCD:

`make BOARD=bluebirdVG015 flash`

## Serial console

The default RIOT stdio console uses `UART3` at `115200` baud.
On the tested board revision this UART is routed to the board's USB-to-UART
connector.
*/
