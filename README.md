# RIOT OS для микроконтроллера К1921ВГ015
Предполагается использовать плату BlueBird-VG015 c программатором BlueProg

(Осторожно: 2 с хвостиком гигабайта! Причина уже изучена и будет исправлена в скором времени.)


## Подготовка:
1) Требуется настроить компилятор. Необходимо установить riscv64-unknown-elf-gcc:
```bash
$ sudo apt install gcc-riscv64-unknown-elf
```
2) Возможно, потребуется указать путь к компилятору в PATH.
3) Требуется взять includes из тулчейна и скопировать без замены в установленный компилятор. В моём случае это выглядело так:
```bash
$ sudo cp -r --update=none /home/mageking/RIOT/boards/bluebirdVG015/toolchain/riscv-gcc/sysroot/usr/include/* /usr/lib/gcc/riscv64-unknown-elf/13.2.0/include
```

## Текущие проблемы: 
1) Прерывания. Необходимо проверить причину и необходимость обращения к CLINT во время исполнения прерывания. Сравнить с официальнрым SDK. В функции riscv_irq_init переписаны обращения к MTHR, mie и mstatus под способ из официальной SDK. Это не правильно, но иначе не работает. Важно, что значения, которые закладываются в эти регистры в SDK и в RIOT - разные. Загадка.
2) toolchain. Пока в он лежит внутри папки платы. И на самом деле не выполняет никакой полезной задачи. Только содержит компилятор и OpenOCD, которые точно работают для этого МК в другом проекте.

## Заметки:
1) Наилучшим образцом пока выступает GD32V. Он немного похож по архитектуре. И у него достаточно простая реализация библиотек. 
2) В процессе работы выяснилось, что SiFive fe310 ещё ближе, но с нюансами. Например, у него отсутствуют аппаратные таймеры.
3) Тем не менее, верхний уровень реализации библиотек для перерферии лучше брать с STM32.
4) Проблема с MSG возникала из-за отсуствия этих строк в boards/bluebirdVG015/Makefile.features:
```makefile
FEATURES_PROVIDED += periph_timer
FEATURES_PROVIDED += periph_uart
```
5) Для plic есть отдельный модуль, который нужно обязательно подключать.
6) Проверять результат компиляции удобно по файлам riotbuild.h.in и riotbuild.h в examples-miem/hello-world/bin/bluebirdVG015/riotbuild/
7) GDB - это вещь
