# RIOT OS для микроконтроллера К1921ВГ015
Предполагается использовать плату BlueBird-VG015 c программатором BlueProg

(Осторожно: 2 с хвостиком гигабайта!)


## Подготовка:
1) Требуется настроить компилятор. Необходимо установить riscv64-unknown-elf-gcc:
```bash
$ sudo apt install gcc-riscv64-unknown-elf
```
2) Возможно, потребуется указать путь к компилятору в PATH.
3) Требуется взять includes из тулчейна и скопировать без замены в установленный компилятор. В моём случае это выглядело так:
```bash
$ sudo cp -r --update=none /home/mageking/RIOT/boards/bluebirdVG015/toolchain/riscv-gcc/sysroot/usr/include/* /usr/lib/gcc/riscv64-unknown-elf/13.2.0/include
```

## Текущие проблемы: 
1) При компиляции возникает ошибка: флаг printf "%u" по размерности не соотвествтует переменной для которой применяется. Скорее всего что-то в настройка компилятора. Пока совершенно не понимаю что именно не так. В списке флагов компиляции есть -march=rv32imac -mabi=ilp32,  которые указывают на требуемую разрядность. Что забавно, для GD32V та же проблема овзникает.
2) Много-много мусора. Наполнение новых файлов по большей части состоит из заглушек. У файлов сейчас задача просто быть. 
3) Скорее всего придётся переходить с riscv-common на vg015-сommon в CPU, так как в riscv-common по определению указываются -march=rv32imac -mabi=ilp32, а это на самом неделе не совсем верно.
4) Ещё раз проверить OpenOCD. Общий OpenOCD почему-то не работает. Пока что на нужный указана прямая ссылка в Makefile.include платы. А ещё ссылка идёт через флаг FLASHER, хотя, возможно, корректнее применить PROGRAMMER. Вдобавок, нужно сделать динамическую ссылку через path, а не указывать путь на прямую туда, где openOCD и не должно быть.
5) toolchain. Пока в он лежит внутри папки платы. И на самом деле не выполняет никакой полезной задачи. Только содержит компилятор и OpenOCD, которые точно работают для этого МК в другом проекте.
